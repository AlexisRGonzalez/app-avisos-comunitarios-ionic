# App Avisos Comunitarios Ionic

Aplicación móvil híbrida para el registro y gestión de avisos comunitarios, desarrollada con Ionic, Angular y Capacitor.

## Descripción

Proyecto desarrollado durante mi formación como Técnico en Informática, orientado al desarrollo de aplicaciones móviles híbridas.

La aplicación permite registrar y gestionar avisos comunitarios mediante una interfaz adaptada para dispositivos móviles.

## Tecnologías utilizadas

- Ionic
- Angular
- TypeScript
- Capacitor
- HTML
- CSS

## Características

- Registro de avisos comunitarios.
- Visualización y gestión de información.
- Interfaz adaptada a dispositivos móviles.
- Desarrollo multiplataforma mediante Ionic y Capacitor.
- Componentes e interfaces desarrollados con Angular.

## Contexto del proyecto

Proyecto académico desarrollado como parte de mi formación en Técnico en Informática en IPLACEX.
